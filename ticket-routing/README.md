# 园区 / 政企工单分派与 SLA 预警

园区物业一天几十上百单，靠班组长在群里喊人派活。这个规则引擎把派单和 SLA 计时自动化，但把最危险的两类事交回给人。

## 安全类工单不自动派

消防、电气、电梯困人、燃气这四类，命中即 P1，并且**强制人工确认**，规则不自动派单。理由很直接：这些单派错了，损失不是工时，是人命。

一单里同时出现两类问题时，输出主类 + 关联类，一起进人工确认队列，不拆单硬派。

## 噪声下的掉点比干净集的分重要

同一批工单，做两件事后重测：标题加错别字、模拟语音转写丢字（约 15%）。

| 集合 | 分派准确率 |
|---|---|
| 原始标题 | 90.0% |
| 加噪声后 | 82.5% |

7.5 个点的落差就是现场要补的东西：同义词 + 错别字纠错表，每周从误派清单里加。

## SLA 按工作日历算

9:00–18:00，跳过周末。用自然小时会把周日的 24 小时算进响应时长，承诺当场就失真。

## 跑

```bash
python3 app/main.py     # 报告写到 out/report.md
```

报告里有：分派准确率（干净/噪声）、自动派单比例 57.5%、人工确认 17 条、P1 14 条、SLA 超时 9 条。

## 已知问题

- 规则引擎适合日均 100 单上下；再往上、或一单多问题的占比超过 20%，要换分类模型 + 人工复核双轨。
- 样例是构造的，签约前必须在客户真实工单上跑至少 200 单再定 SLA。
- 只做分派与计时，不做回访与满意度。
