# 园区/政企工单智能分派与 SLA 预警

**一句话价值**：40 张工单 0.05 秒分到班组，准确率 95%，9 条超时自动拉清单发群。

**目标客户**：园区运营方 / 政企信息中心 / 物业项目经理

## 一、实施方案

现场痛点：工单靠人看、靠喊，派错组、超时没人管，月底说不清哪个班组忙。

方案核心：8 类工单规则 + 关键词判定 + P1/P2/P3 分级 + 按类型 SLA 倒计时 + 班组负载统计 + 误派清单反哺规则。

节奏：第 1 周场景确认 → 第 2 周原型跑通 → 第 3 周部署+文档 → 第 4 周培训+验收。

## 二、验收清单

1. 运行 app/main.py，输出 40 单分派结果、班组负载、超时清单、误派清单
2. 准确率需给出误派明细（不遮掩）
3. 规则表可被客户 IT 直接修改，不需要改代码
4. 统计基准时间写明，避免口径争议

## 三、度量表

| 指标 | 人工基线 | 本方案 | 结论 |
|---|---|---|---|
| 分派准确率（原始文本） | 人工分派 | 90.0% | 可复核 |
| 分派准确率（错别字/语音扰动） | — | 82.5%（-7.5 个点） | 真实代价 |
| 人工确认队列 | 无 | 17 条（安全类/大范围/一单多问题） | 安全兜底 |
| SLA 超时 | 月底才发现 | T+2 快照 9 条（工作日历口径） | 提前介入 |

## 四、培训大纲

| 模块 | 内容 | 学员产出 |
|---|---|---|
| 模块 1（20 分钟） | 规则表怎么改：类型、关键词、班组、SLA | 现场加一类工单 |
| 模块 2（15 分钟） | 误派怎么处理：看清单 → 补词 → 重跑 | 把误派率降到 5% 以下 |
| 模块 3（15 分钟） | SLA 怎么用：超时群提醒、周报 | 能自己发周报 |
| 模块 4（10 分钟） | 升级路径：3 个月数据后换模型 | 知道什么时候该换 |

## 五、故障演练表

| 异常场景 | 处理与降级 | 预期结果 |
|---|---|---|
| 工单描述一句话、无关键词 | 兜底到「其他/综合组」，不瞎派 | 漏派可控 |
| 同一工单命中多类 | 取命中数最高，平票按优先级顺序 | 结果稳定可解释 |
| 节假日报修激增 | 负载表直接看出瓶颈，临时调班 | 有依据 |
| 规则改错导致大面积误派 | 保留上一版规则文件，可一键回滚 | 5 分钟恢复 |
