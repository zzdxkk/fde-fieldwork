# 设备运维知识库问答（内网离线版）

**一句话价值**：拔掉网线也能用：每条回答带出处，查不到就拒答转人工，杜绝一本正经胡说。

**目标客户**：工厂设备科 / 园区物业 / 制造企业 IT

## 一、实施方案

现场痛点：老师傅经验在脑子里，新人问十遍没人答；上了大模型又不敢用，怕它编。

方案核心：BM25 检索（零依赖、无外部 API）+ 双闸门（分数阈值 + 实词重合≥2）+ 强制引用出处 + 无依据转人工。

节奏：第 1 周场景确认 → 第 2 周原型跑通 → 第 3 周部署+文档 → 第 4 周培训+验收。

## 二、验收清单

1. 运行 app/main.py 输出 out/report.md，逐条给出命中条目与编号
2. 域外问题（年会时间）必须拒答并转人工
3. 每条命中必须带 KB 编号，客户可自行核对原文
4. 断网状态下运行成功

## 四、培训大纲

| 模块 | 内容 | 学员产出 |
|---|---|---|
| 模块 1（20 分钟） | 怎么加一条知识：标题、正文、关键词写法 | 现场新增 1 条并检索命中 |
| 模块 2（15 分钟） | 怎么判断答得对不对：看分数与出处 | 能识别低分答案并转人工 |
| 模块 3（15 分钟） | 拒答不是故障：转人工流程怎么走 | 明确谁接单、多久回 |
| 模块 4（10 分钟） | 知识库维护节奏：每周补 5 条 | 形成维护台账 |

## 五、故障演练表

| 异常场景 | 处理与降级 | 预期结果 |
|---|---|---|
| 问法太口语、术语不匹配 | 双闸门先拒答，人工补同义词后重跑 | 误拒可控，避免错答 |
| 知识库没有的新故障 | 低于阈值直接转人工，不生成猜测 | 客户信任不塌 |
| 两条知识高度相似 | 取分数最高一条，附相似条目提示 | 不出现自相矛盾 |
| 并发 20 人同时查 | 纯本地检索实测毫秒级，无需 GPU | 无排队 |
