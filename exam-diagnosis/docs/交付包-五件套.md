# 高中数学错题诊断与班级教学决策助手

**一句话价值**：把「30 个班、600 条答题记录」变成「4 个必补知识点 + 8 个学生干预清单」，教师 2 分钟拿到手。

**目标客户**：教研组长 / 年级主任 / 培训机构教学负责人

## 一、实施方案

现场痛点：批改完只知道「考得不好」，不知道「哪个知识点全班都错了、哪个学生是审题问题」；统计靠 Excel 手搓，一次 80 分钟。

方案核心：规则化错因归因（5 类）+ 知识点掌握度分档 + 班级热力表 + 个体 top3 薄弱点 + 分层干预话术。

节奏：第 1 周场景确认 → 第 2 周原型跑通 → 第 3 周部署+文档 → 第 4 周培训+验收。

## 二、验收清单

1. 给定 answers.csv，运行 app/main.py 输出 out/report.md
2. 报告含：班级掌握度表、必补知识点排序、错因结构、个体清单、下节课 3 个动作、度量表
3. 错误类型 5 类全覆盖，未出现的错因不硬凑
4. 无网络环境下可完整运行（已验证）

## 三、度量表

| 指标 | 人工基线 | 本方案 | 结论 |
|---|---|---|---|
| 录入+归因+统计耗时 | 约 82 分钟（手工口径） | 2.1 分钟 | -97% |
| 规则-教师标注一致率 | — | 65.1%（规则可判定 87.6%） | 证明归因不能自动化 |
| 错因来源 | 教师口头、难追溯 | 教师标注落库，可回溯作答片段 | 可审计 |
| 覆盖学生 | 抽查 5–8 人 | 全部 30 人 | 全覆盖 |

## 四、培训大纲

| 模块 | 内容 | 学员产出 |
|---|---|---|
| 模块 1（20 分钟） | 看懂报告：三个表分别回答什么问题 | 教师能自己指出本周该补哪个知识点 |
| 模块 2（30 分钟） | 数据怎么填：答题明细表字段与填报规范 | 能独立导出一份可运行的 CSV |
| 模块 3（20 分钟） | 怎么改规则：知识点、错因、干预话术模板 | 改一处规则并重跑成功 |
| 模块 4（10 分钟） | 交接与留痕：报告归档、教研会用法 | 形成每周固定动作 |

## 五、故障演练表

| 异常场景 | 处理与降级 | 预期结果 |
|---|---|---|
| CSV 字段错位 / 缺列 | 读入前做字段校验，缺列直接报错并打印表头 | 1 分钟内定位到具体行 |
| 某知识点样本量 < 2 | 不计算正确率，标注「样本不足」 | 不输出误导性结论 |
| 全部答对 / 全部答错 | 分档逻辑仍给出「已掌握/薄弱」，不除零 | 无 NaN、无崩溃 |
| 学生数从 30 增到 300 | 纯本地计算，实测 600 行 < 1 秒，300 人量级仍秒级 | 无需改架构 |
