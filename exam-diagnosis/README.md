# 高中数学错题统计与教学决策助手

一次考试、30 个学生、600 条作答记录，转成下节课能直接用的东西：哪个知识点没掌握、错因结构是什么、每个学生该做什么、下节课三个动作。

## 先说边界：错因不做自动归因

教师标注的 `teacher_error_type` 是事实来源。脚本用文本特征规则给一个"可能是这类"的提示，并用一致率证明它只能当排序提示：

- 规则可判定比例 87.6%（193 条里判得出 169 条）
- 规则与教师标注一致率 65.1%
- 两者不一致的 10 条样例留在报告里，方便教师看规则是怎么错的

如果把它包装成"AI 自动诊断"，65.1% 的准确率会让老师第一次用就失去信任。这是刻意保留的边界，不是没做完。

## 跑

```bash
python3 app/main.py           # 正常
python3 app/main.py --mask    # 学生 ID 哈希脱敏，对外演示用这个
```

报告写到 `out/report.md`。

## 报告里有什么

| 段 | 内容 |
|---|---|
| 知识点掌握度 | 按难度加权后的掌握率，带样本量，样本少于 15 条的标"证据不足" |
| 错因结构 | 各类错因占比 + 教师给出的处理策略 |
| 规则一致性 | 可判定比例、一致率、分歧样例 |
| 个体清单 | 每个学生的薄弱点与建议动作，按优先级排 |
| 下节课三个动作 | 从上面几段里挑影响面最大的三条 |
| 度量 | 人工基线 82 分钟（无阅卷系统）/ 30 分钟（已有阅卷机）vs 本工具 2.1 分钟 |

## 数据

`app/data/answers.csv`：学生 ID、题号、知识点、作答文本、教师标注错因。首次运行时若文件不存在会生成一份构造样例。

样例数据是构造的，只证明机制成立，不证明任何真实班级的可用率。

## 已知问题

- 规则靠关键词，遇到"用了单调性结论但端点没验"这种复合错因会判成"概念不清"，需要教师在提示上二次确认。
- 一个学生同一知识点错了三次以上才进个体清单，只错一次的不打扰老师。
- 没做换人换机复现。
