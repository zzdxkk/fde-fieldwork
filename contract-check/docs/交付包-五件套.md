# 合同/采购材料一致性核查（规则本体）

**一句话价值**：20 份合同 0.02 秒筛完，10 份高风险逐条指出「哪条超限、怎么改」，还附回退话术。

**目标客户**：集团内审 / 采购合规 / 法务支持

## 一、实施方案

现场痛点：合同条款靠人逐份看，25 分钟一份，看得慢还容易漏；业务部门觉得你在挑刺。

方案核心：7 条条款本体规则（预付/质保/违约金/交付期/账期/验收标准/发票税率）+ 风险分级 + 问题分布 + 回退话术。

节奏：第 1 周场景确认 → 第 2 周原型跑通 → 第 3 周部署+文档 → 第 4 周培训+验收。

## 二、验收清单

1. 运行 app/main.py，输出风险分级、问题分布、高风险明细、回退话术
2. 每条问题必须写「实际值 vs 阈值」，不能只给结论
3. 7 条规则可增删，阈值可配置
4. 高风险合同逐份列出问题点

## 三、度量表

| 指标 | 人工基线 | 本方案 | 结论 |
|---|---|---|---|
| 高风险占比 | 50%（一刀切） | 30%（豁免 + 金额门槛） | 业务可接受 |
| PDF 字段抽取准确率 | 人工读 | 96.3%（27 个字段） | 失败字段已列 |
| 单份核查耗时 | 约 25 分钟 | 全量 20 份 0.02 秒 | -99% |
| 阈值来源 | 拍脑袋 | 逐条标来源，未确认的标「待确认」 | 可追责 |

## 四、培训大纲

| 模块 | 内容 | 学员产出 |
|---|---|---|
| 模块 1（20 分钟） | 规则本体怎么读：字段、阈值、等级 | 能自己加一条规则 |
| 模块 2（20 分钟） | 高风险怎么退回：话术与两个改法 | 业务部门接受度提升 |
| 模块 3（15 分钟） | 例外审批怎么留痕 | 有台账 |
| 模块 4（10 分钟） | 批量筛查 + 抽检复核机制 | 每月抽检 10% |

## 五、故障演练表

| 异常场景 | 处理与降级 | 预期结果 |
|---|---|---|
| 合同字段缺失（空值） | 按「未写明」判为中/高风险，不跳过 | 不漏检 |
| 阈值刚过线（如预付 31%） | 按规则判超限，人工确认是否为特批 | 不误伤也不放过 |
| 新业务条款规则没覆盖 | 落入「其他」清单，人工补充规则 | 规则持续生长 |
| 批量 500 份 | 纯本地规则匹配，实测 20 份 0.02 秒，500 份仍秒级 | 无需换架构 |
